# Slice 2 — Semantic restriction universe and origin mapping

**Goal:** derive a deterministic, complete semantic conflict universe from one exact `BackendSnapshot`, with reversible toggles and lossless bound-layer restoration.

**Requirements/decisions:** packet D3, D28 and §7; R2.6, R2.8, R3.5, R4.1; future function-in-set seam.

## Files and interfaces

- Create `src/compiler/restriction.rs` with `ConflictAtomId`, `ConflictAtomKind`, `CompiledRestrictionRef`, `RestrictionTogglePlan`, `RestrictionSelection`, `ConflictGrouping`, `ConflictOrigin`, `ConflictMemberSnapshot`, and `SemanticConflictUniverse::from_snapshot(&BackendSnapshot, InfeasibilityScope, ConflictGrouping) -> Result<Self, InfeasibilityError>`.
- Extend `src/compiler/origin.rs` with `RestrictionOriginMap`, keyed by exact `CompilationId`, beside (not instead of) `OriginMap`. `map_compiled(compilation_id, ref)` and `atom(compilation_id, id)` reject stale identities before reading or changing state.
- Extend `src/compiler/bounds.rs` and the owning model/overlay modules with a bound contribution stack. A layer stores source, lower/upper value, semantic atom, and restoration predecessor; removing a higher layer reinstates the predecessor.
- Extend `src/compiler/session.rs`/`report.rs` to preserve original entity names, sides, values, source metadata, construct role, and compiled references in immutable snapshots.
- Create `tests/restriction_universe.rs`; extend `tests/fixing_assignment.rs` and `tests/compiler_identity.rs`.

## Test-first execution

- [ ] **1. Write failing atom inventory tests.** Build fixtures with a one-sided row, equality, ranged row, variable lower/upper bounds, persistent fixing, solve lock, temporary fixing, and one construct that emits multiple compiled restrictions. Assert the expected atom count, kinds, stable declaration order, and grouped compiled references.
- [ ] **2. Write failing bound-stack tests.** Apply declared bounds, then persistent fixing, then a solve lock/temporary fixing. Disable each upper layer in turn and assert the exact lower layer is restored; explicitly assert that no layer is restored to infinity when a predecessor exists.
- [ ] **3. Write failing completeness/staleness tests.** Assert every active compiled row side, bound side, fixing, overlay restriction, and generated construct role appears exactly once in the selected grouping. Forge a different `CompilationId`, missing origin, duplicate atom ID, and malformed toggle plan; all reject before backend mutation.
- [ ] **4. Write failing historical snapshot tests.** Mutate the source model after building the universe and assert report snapshots retain names/values/provenance while live re-resolution rejects mismatched instance/revision/`CompilationId`.
- [ ] **5. Implement deterministic compilation.** Build atom records and reversible toggles from `BackendSnapshot`; preserve compiled indices and avoid deleting/re-adding native rows. Keep canonical model state untouched.
- [ ] **6. Run property/mutation checks.** Generate bounded layer/enable-disable sequences and compare disable/restore state with a full snapshot rebuild. Run `cargo test -p roml --test restriction_universe --test fixing_assignment --test compiler_identity` plus core clippy/doc checks; record coverage and failures.

## Acceptance and stop conditions

No oracle work begins until every semantic atom has complete compiled coverage, exact identity checks, stable ordering, and a reversible toggle. Stop if a grouped construct cannot be disabled atomically, if a bound layer cannot restore its predecessor, or if the universe requires a matrix-row-only public member.

**Commit boundary:** `feat(iis): add semantic restriction universe and bound stacks`.
