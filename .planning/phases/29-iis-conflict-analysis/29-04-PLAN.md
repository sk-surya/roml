# Slice 4 — ROML reducer and mandatory verifier

**Goal:** implement the deterministic portable reducer and prevent every incomplete, stale, or insufficiently verified run from claiming semantic irreducibility.

**Requirements/decisions:** packet §5.3–§5.6, D1–D2; R3.5, R4.2, R8.3.

## Files and interfaces

- Create `src/solver/reducer.rs` with an internal reducer trait, cheap contradiction scan, seed selection, adaptive chunk deletion, exact single-atom deletion polish, and `ReducedConflict`/`ReductionStatistics`.
- Extend `src/solver/infeasibility.rs` with the orchestration sequence: exact compilation → universe → oracle → initial check → seed → reducer → fresh verifier → report. The public entry point remains on `SolverSession`.
- Extend `src/solver/reference.rs` with planted conflicts, multiple valid IIS fixtures, call/iteration/time budgets, Unknown injection, and counters.
- Create `tests/iis_reducer.rs`; extend `tests/iis_mutation.rs` and `tests/differential_harness.rs`.

## Test-first execution

- [ ] **1. Write entry-state tests.** Prove a feasible model returns canonical `NoConflict`; an unknown initial check returns incomplete evidence; an infeasible universe proceeds; an explicitly unsupported MIP-only conflict returns typed `Unsupported`/`NoConflictInRequestedScope` rather than silently analyzing the wrong scope.
- [ ] **2. Write seed/reducer tests.** Cover direct contradictory bounds/rows, full-universe fallback, deterministic seed order, native/Farkas/elastic seed hooks, adaptive power-of-two chunks, and exact single-atom polish. Assert a valid pair remains after deleting irrelevant atoms.
- [ ] **3. Write guarantee tests.** For every complete portable result independently check all members together as `ProvenInfeasible`, then check every member removal as `ProvenFeasible`. Assert any Unknown deletion, exhausted budget, interruption, numerical status, or failed final verification yields `InfeasibleSubsystem`/`None`, never `Irreducible`.
- [ ] **4. Write multiple-IIS tests.** Use two disjoint conflicts and assert one valid IIS is returned without `Smallest`, `MinimumCardinality`, `AllIis`, or equivalent vocabulary. Native and portable member sets need not be equal when both are valid.
- [ ] **5. Implement reducer and verifier.** Use deterministic stable atom order, monotonic deletion, adaptive chunks before single-atom polish, and a fresh final check that does not reuse a stale cached answer. Record candidate sizes, oracle calls, iterations, rebuilds, cache hits, and verifier results.
- [ ] **6. Run mutation tests.** Mutate Unknown-to-infeasible mapping, final-verifier bypass, bound restoration, stale-selection acceptance, and guarantee promotion. Each mutation must fail at least one test. Run focused tests and update `P29_REDUCER.md` with actual mutation operators/results.

## Acceptance and stop conditions

No report can claim `Irreducible` without the fresh final verification pass. Stop if an optimization changes final verification or guarantee semantics, if a cache can cross exact identity/policy boundaries, or if the reducer begins to enumerate all IISs or optimize cardinality.

**Commit boundary:** `feat(iis): add portable LP conflict reduction and verification`.
