## Trust Boundaries

| Boundary | Description |
|---|---|
| Relaxation request → façade | User-supplied restrictions, caps, weights, provider, and acceptance enter a solve attempt. |
| Overlay → persistent backend session | Temporary rows/bounds/objectives cross into a mutable solver session. |
| Backend result/error → report | Untrusted termination and cleanup state are normalized into public outcomes/errors. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-30-07 | Tampering | relaxation request validation | high | mitigate | Validate exact identities, finite weights, scope, and provider policy before backend mutation. |
| T-30-08 | Denial of service | weighted-L1 overlay | medium | mitigate | Honor immutable solve request limits and classify limits as `Unknown` rather than looping or fabricating success. |
| T-30-09 | Tampering | overlay rollback | critical | mitigate | Require exact compilation/receipt verification, preserve composite errors, and force rebuild on uncertainty. |
| T-30-10 | Repudiation | relaxation report | medium | mitigate | Record provider, termination, numeric evidence, model identity, and both compilation identities. |
</threat_model>
